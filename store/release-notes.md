# Release notes

Play Console → Production → Create new release → "What's new in this release".
The limit is 500 characters per language. Keep the current release's text at the
top and leave the older entries below it as a record.

## 1.0.0 (versionCode 1)

```
Baseline is an offline tracker for strength and cardio training.

- Two planning modes: static raises its own weights as you get stronger, periodized holds the prescription for a whole program.
- Supersets and circuits, with a rest timer that starts itself.
- Structured runs, and pace that fills in its own third number.
- Progress charts, personal records, and full backup and restore.

No account, no ads, and no internet permission.
```
